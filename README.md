# 機密情報黒塗くん

AIに渡す前に、文章の中の伏せたい情報を自分で選ぶためのツールです。インストール不要の単一HTMLをダウンロードし、手元のブラウザーで使います。

## ダウンロードして使う

1. **[HTMLをダウンロード](https://github.com/shota0e0/kimitsu-mask/raw/refs/heads/main/kimitsu-mask.html)** を右クリックして「名前を付けてリンクを保存」を選び、`kimitsu-mask.html` として保存してください。リンクを開いてダウンロードが始まる場合は、そのファイルを使えます。
2. 保存したHTMLをダブルクリックし、EdgeまたはChromeで開きます。アドレスが `file:///` で始まることを確認してください。
3. まず「詳細設定」→「架空サンプル」で動作を確認してください。

直接保存できない場合は、このページ上部の **Code → Download ZIP** から取得し、展開した中の `kimitsu-mask.html` を開いてください。

## 基本操作

- 「原文」に文章を貼り付け、「ワンクリック匿名化」を押します。人名・企業名・連絡先の検出は補助です。検出漏れや誤検出を目視で確認してください。
- 追加で伏せたい部分は原文中で選択し、「選択範囲を黒塗り」を押します。同じ文字列をまとめて置換する操作も選べます。
- 「匿名化文」を確認・必要に応じて編集し、「コピー」でコピーします。原文・置換ルール・数値設定を変更した後、編集稿が保持されている場合は明示的な再生成が必要です。
- AIの回答を「復元」タブに貼り付け、「置換表から復元」を押します。同じ画面で保持している現在の置換表を使います。回答や置換表が変わったら再復元してください。
- 作業後は「全消去」を押してください。ブラウザーやOSに残る履歴・メモリー等の完全消去を保証する機能ではありません。

数値のダミー化は初期状態でOFFです。ONにした数値は復元できず、倍率などから元データを推測できる場合があります。辞書のJSON保存は明示操作のみです。保存した辞書も機密情報として管理し、GitHubへアップロードしないでください。

## データの扱いと利用上の境界

配布HTMLのアプリコードに、外部API・CDN・アクセス解析・外部送信処理・自動保存処理はありません。HTML内のCSPでも外部接続を禁止しています。原文・置換表・辞書をGitHubへ送る機能はありません。

ただし、ブラウザー自身、拡張機能、OS、IME、クラウドクリップボード、履歴・キャッシュ・セッション復元・端末バックアップなどは、このHTMLの管理範囲外です。取得や残存、端末からの通信が完全に防げることを保証しません。利用端末と拡張機能を確認し、所属先のデータ取扱規程に従ってください。

GitHubはソースとHTMLの配布先です。ダウンロード時の接続情報はGitHub側に届きます。ホスティングやアカウントの変更・侵害によって、配布物が変更される可能性もあります。入手元と下記のSHA-256を確認してから使ってください。ハッシュも同じ配布元にあるため、それ単独で発行者の真正性を保証するものではありません。

**GitHub Pagesによるオンライン実行版は提供していません。** 原文をオンラインの公開ページに入力せず、ダウンロードしたHTMLをローカルで開いて使ってください。AIサービスに貼り付けると、その時点でそのサービスへの送信になります。匿名化が入力許可や完全な秘匿を保証するわけではありません。

## 版と既知の制約

HTML v0.4。KIMITSU-006の受入済みHTMLを基準とし、現行正式HTMLにあるKIMITSU-007の復元通知欄の表示整理を含めて配布しています。この通知欄差分のOwnerによるUI受入は未了です。006の受入を差分全体の受入とは扱っていません。公開のためのアプリコード変更は行っていません。

- 検出候補は最大90件で、検出の網羅性は保証しません。
- 入れ子・壊れた未知トークンの扱いに既知の制約があります。
- 復元は現在の置換表にあるトークンが対象です。AIが変えた表記・独自別名・数値は復元できない場合があります。
- アプリの自動保存はありません。ページを閉じたり再読み込みしたりすると、作業を継続できなくなる場合があります。
- 実際のブラウザー・会社PCでの動作や、OSのクリップボード・保存ダイアログは今回の配布検証では未確認です。
